# Deep Image Matting Dataset

This repository provides the foregrounds and alphas for the Deep Image Matting dataset as described in the CVPR 2017 paper:

### &emsp; Deep Image Matting
&emsp;&nbsp; Ning Xu, Brian Price, Scott Cohen, Thomas Huang.  CVPR 2017

&emsp;&nbsp; [[Paper]](http://openaccess.thecvf.com/content_cvpr_2017/papers/Xu_Deep_Image_Matting_CVPR_2017_paper.pdf) 
[[Project page]](https://sites.google.com/view/deepimagematting) 

## Download dataset
The dataset can be downloaded [here](https://github.com/adobe-research/Deep_Image_Matting_Dataset/releases/tag/v1.0).
